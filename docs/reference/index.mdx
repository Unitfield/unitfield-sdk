This is an index of the operations in the OpenAPI snapshots committed beside the SDK (`packages/sdk/openapi`). The SDK's types
are generated from the same files, and its contract tests check every call against them, so an operation listed here is what
the SDK can call. Request and response shapes are in the JSON files and in the SDK's types (`StorefrontPaths`, `CustomerPaths`,
`ResidentPaths`, `AppsPaths`, `PlatformPaths` and `CustomerAuthPaths`, with matching `...Components` and `...Operations`).

The API root is `https://api.unitfield.com`.
