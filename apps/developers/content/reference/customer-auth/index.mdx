---
title: Customer auth API
description: Sign-in challenges, sessions and account changes for customers. First-party servers only.
---

These operations run a customer's sign-in on an organization's hosted pages: a six-digit code sent by email, the session that follows,
step-up and account changes. Unitfield's own servers call them with signed service requests. Browsers and SDK sites never call them,
and the SDK has no client for them.

To sign customers in on your own site, you do not need this API: use [customer sign-in with PKCE](/docs/customer-sign-in).
